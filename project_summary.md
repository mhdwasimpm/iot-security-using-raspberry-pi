# Project Summary

## Project Title

IoT Security Using Raspberry Pi

## Overview

This project implements a lightweight Intrusion Detection System (IDS) using Raspberry Pi and Snort IDS to enhance the security of IoT environments. The system monitors network traffic, detects suspicious activities, and generates real-time alerts through Telegram notifications.

## Key Features

* Snort-based Intrusion Detection
* Raspberry Pi Security Monitoring
* Telegram Alert Notifications
* IoT Camera Monitoring
* Custom Detection Rules
* Real-Time Threat Detection

## Technologies Used

* Raspberry Pi 4 Model B
* Snort IDS
* Python
* Flask
* Telegram Bot API
* Kali Linux

## Attack Detection Capabilities

* Nmap SYN Scan Detection
* ICMP Flood Detection
* HTTP Flood Detection
* SSH Brute Force Detection
* Network Reconnaissance Detection

## Outcomes

* Improved visibility into IoT network traffic.
* Real-time detection of malicious activities.
* Automated alert generation and notification.
* Successful validation through attack simulations.
* Research paper publication in IJRASET.
